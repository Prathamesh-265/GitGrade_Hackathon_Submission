# GitGrade Pro 🚀  
AI-Powered GitHub Repository Evaluator

## Overview
GitGrade Pro analyzes any **public GitHub repository** and converts it into a:
- **Score (0–100)**
- **Honest project summary**
- **Personalized improvement roadmap**

It helps students understand how their code looks to **recruiters and mentors**.

---

## Features
- Accepts GitHub repository URL
- Uses real GitHub API data
- Evaluates:
  - Code structure
  - Documentation quality
  - Commit consistency
  - Test presence
  - Project completeness
- Generates actionable feedback

---

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express  
- **API:** GitHub REST API
